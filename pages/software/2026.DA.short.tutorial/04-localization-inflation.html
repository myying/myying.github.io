Localization and inflation

1 · Localization: the fix for sampling noise

A small ensemble estimates covariance noisily. This widget shows the ensemble's estimate next to the true covariance, so you can see the noise directly. With localize on, the sample covariance is tapered to exactly zero beyond radius L — keeping the reliable signal near the observation and discarding the noisy far field, real or not.

Try it: drag the observation, and slide the ensemble size down to see the sample map fill with spurious blobs. Turn localization on and dial the radius.

2 · Inflation: the fix for missing spread

Localization fixes noise in space. Inflation fixes a different problem: an ensemble that's lost its spread has nothing left to correct itself with. This storm-tracking widget is the same as Chapter 3's, except every member now drifts noticeably slower than the truth, cycle after cycle. Without spread, the ensemble stays confidently wrong. Inflation fixes that here in the simplest way — after each analysis, give every member's position an independent random kick, sized by the slider.

Try it: run with the perturbation at 0 — the ensemble mean falls steadily behind the truth. Raise it to 5–8 km and run again — the extra spread gives the next analysis enough leverage to correct the bias each cycle. Push it much higher and it gets worse again: more spread isn't automatically more accuracy.

Real systems use other flavors of inflation too (multiplicative scaling, relaxation to prior spread), but the idea is always the same: put back some of the spread the analysis removes, so the ensemble stays honest about how wrong it might be.
