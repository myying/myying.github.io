The ensemble Kalman filter

The covariance matrix is too big to store, so the ensemble carries it: the analysis becomes a linear combination of ensemble perturbations. A planned widget will show an ensemble of state points being pulled toward an observation, with the update determined by the ensemble covariance itself — no matrix ever assembled.

→ Evensen et al., Data Assimilation Fundamentals (2022), Ch 8 — ensemble methods and the EnKF update.
